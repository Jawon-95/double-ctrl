## 新增

- 切换主题时颜色平滑过渡，滑块带滑动动画
- 翻译窗口出现和消失时有缩放动画

## 改进

- 托盘图标和窗口里的图标保持一致
- 程序遇到异常时不再退出，错误记录在 `%APPDATA%\DoubleCtrl\crash.log`

## 修复

- 在托盘菜单里切换主题时，菜单不会立即变色
- 从浅色切换到深色或系统主题时，滑块变亮导致文字看不清

## 安装

下载 `DoubleCtrl.exe` 直接运行，不需要安装。需要 Windows 10 1903 或更高版本。

程序没有数字签名，首次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”再点“仍要运行”即可。
