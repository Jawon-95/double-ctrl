## 新增

- **输入翻译**：光标在输入框里、没有选中文字时双击 Ctrl，输入框旁会弹出一个编辑框。
  - 用中文写，停顿一下，译文就自动填进原输入框；修改原文后，译文也会跟着更新。
  - 按 Enter 立即翻译，按 Shift+Enter 换行。
  - 支持记事本等普通输入框，也支持浏览器和 Claude 等 Electron 程序。

## 修复

- 部分中文词语（如“主控”“审核”“提交”）每次翻译结果都不一样，而且与原文无关

## 安装

下载 `DoubleCtrl.exe` 直接运行，不需要安装。需要 Windows 10 1903 或更高版本。

程序没有数字签名，首次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”再点“仍要运行”即可。
