Double Ctrl 首个正式版本。选中文字，双击 Ctrl，立刻翻译。

## 功能

- 在任意程序里划词翻译，包括资源管理器的重命名框和地址栏
- 单词显示音标、发音、释义和网络释义，句子直接翻译
- 支持英、法、日、韩、德、西、俄、葡与中文互译
- 翻译后恢复剪贴板，不在 Win+V 历史里留下记录
- 拖动窗口自动固定，方便对照参考
- 深浅主题，默认跟随系统
- 静默启动和开机自启

## 安装

下载 `DoubleCtrl.exe` 直接运行，不需要安装。需要 Windows 10 1903 或更高版本。

程序没有数字签名，首次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”再点“仍要运行”即可。
