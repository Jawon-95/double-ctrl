## 新增

- **自动检测语种**：语言菜单新增“自动检测，译成”一栏，自动识别原文语种，译成选定的语言（中、英、日、韩、法、德、西、俄、葡）。外文之间互译会经中文中转。

## 改进

- 语言菜单分成“自动检测”和“指定语种”两栏并排显示
- 输入翻译的编辑框在很宽的输入框里会出现在鼠标附近，不再总贴着输入框左边
- 鼠标移出可见的卡片区域就会收起窗口，阴影和透明边缘不再算在窗口内

## 安装

下载 `DoubleCtrl.exe` 直接运行，不需要安装。需要 Windows 10 1903 或更高版本。

程序没有数字签名，首次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”再点“仍要运行”即可。
