## 新增

- **源语言和目标语言分开选**：窗口标题栏改成“源语言 ⌄ ⇄ 目标语言 ⌄”。源语言可选自动检测，点 ⇄ 互换。外文之间互译会经中文中转。
- **托盘菜单切换语言**：右键托盘图标，最上面就能切换翻译语言。
- **自动更新**：启动后（以及之后每天）检查新版本，自动下载，在你不用翻译窗口时替换并重启。
- 窗口底部显示当前版本号。

## 改进

- 新图标：深色底、地球和“A / 文”气泡，各尺寸都清晰。
- 提示文字更简短，不再换行。
- “更多”菜单去掉了重复的语言选项。

## 安装

下载 `DoubleCtrl.exe` 直接运行，不需要安装。需要 Windows 10 1903 或更高版本。

程序没有数字签名，首次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”再点“仍要运行”即可。

从 1.3.0 起会自动更新；1.2.0 及更早的版本需要手动下载这一次。
