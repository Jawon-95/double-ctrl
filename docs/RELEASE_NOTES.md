## 修复

- **Codex 等 ProseMirror 输入框里的输入翻译不同步**：在翻译框里反复删改时，原输入框的内容会越积越多；在翻译框里清空（如 Ctrl+A 删除）时必定提示“没能写入原输入框”。现在每次都会准确替换上次写入的译文。
- 打开输入翻译后，偶尔会因为写入译文时剪贴板发生变化，被误判成划词结果而变成查词窗口，现已修复。

## 安装

下载 `DoubleCtrl.exe` 直接运行，不需要安装。需要 Windows 10 1903 或更高版本。

程序没有数字签名，首次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”再点“仍要运行”即可。

1.3.0 及以上版本会自动更新到此版本；1.2.0 及更早的版本需要手动下载这一次。
