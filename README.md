<h1 align="center">Double Ctrl</h1>

<p align="center">选中文字，双击 Ctrl，立刻翻译。一个不到 150 KB 的 Windows 划词翻译小工具。</p>

<p align="center">
  <img src="docs/screenshot.png" width="640" alt="浅色和深色主题下的翻译窗口">
</p>

## 功能

- **划词翻译**：在任意程序里选中文字，双击 Ctrl 弹出翻译。中文译成英文，英文译成中文。
- **覆盖面广**：资源管理器的重命名框和地址栏、对话框、浏览器、终端里都能取词。
- **词典和句子**：单词显示音标、发音、释义、网络释义和词形变化，句子直接给出译文。
- **多语言**：支持英、法、日、韩、德、西、俄、葡与中文互译，日、韩、俄文会自动识别。
- **不打扰**：弹窗不抢焦点，重命名不会被打断；翻译完剪贴板内容恢复原样，也不会在 Win+V 历史里留下记录。
- **可以固定**：拖动窗口后自动固定在最前面，方便对照参考，点叉号关闭。
- **深浅主题**：默认跟随系统，也可以手动切换。
- **免费**：不用注册，不用登录，不用配置 API Key。

## 安装

从 [Releases](https://github.com/Jawon-95/double-ctrl/releases/latest) 下载 `DoubleCtrl.exe`，放到任意目录后双击运行，不需要安装。

系统要求：Windows 10 1903 或更高版本，这些系统自带所需的 .NET Framework 4.8。

程序没有数字签名，首次运行时 Windows 可能提示“已保护你的电脑”，点“更多信息”再点“仍要运行”即可。

## 使用

| 操作 | 效果 |
| --- | --- |
| 选中文字后双击 Ctrl | 翻译选中内容 |
| 没有选中文字时双击 Ctrl | 打开窗口，可以直接输入 |
| 在翻译窗口里选中文字后双击 Ctrl | 原地翻译选中内容 |
| 鼠标移到窗口上 | 显示标题栏 |
| 拖动标题栏 | 移动并自动固定窗口 |
| 点击窗口外部 | 隐藏窗口（已固定时不隐藏） |
| Esc 或点叉号 | 关闭窗口 |
| 左键点托盘图标 | 打开窗口 |
| 右键点托盘图标 | 打开菜单 |

点窗口右上角的 ⋮ 或右键托盘图标可以设置：

- **静默启动**：启动时不弹窗口，只在后台运行。
- **开机自启**：登录 Windows 后自动在后台运行。
- **主题**：跟随系统、浅色或深色。

配置保存在 `%APPDATA%\DoubleCtrl`。

## 已知限制

- 以管理员权限运行的窗口里取不到词，除非 Double Ctrl 也以管理员身份运行。
- JetBrains 系列 IDE 没有选中文字时，可能会翻译光标所在的整行。
- 无法选中的文字取不到，比如图片里的文字。
- 需要联网。

## 从源码构建

只需要 Windows 自带的 .NET Framework 编译器，不用安装 SDK：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物在 `bin/DoubleCtrl.exe`。

## 声明

Double Ctrl 是个人开发的独立项目，与网易有道没有任何关联。翻译结果来自有道词典的网页接口，
接口的内容和可用性由有道决定，随时可能变化，请遵守其服务条款。

选中的文字会发送给有道接口用于翻译，请不要用它翻译敏感内容。
